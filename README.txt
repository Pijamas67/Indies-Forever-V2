Indies Forever - README

* Descripción

Plataforma web para promoción de videojuegos independientes. SPA que muestra información sobre juegos indie, eventos y permite contacto con la comunidad.

* Tecnologías

Frontend: HTML5, CSS3, Bootstrap 5.0.2
JavaScript: jQuery 3.6.0
Arquitectura: SPA (Single Page Application)
